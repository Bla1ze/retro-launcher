Troubleshooting

The usual problems and their fixes, and how to send a useful bug report.

A game won't start

When a game can't start, Retro Launcher goes back to the menu and says why. The common causes:

  • A BIOS is missing. NAOMI, Atomiswave and Neo Geo always need theirs. Open Settings > BIOS check: it lists what's missing and where it goes.
  • The wrong romset (arcade). A dimmed arcade game says why; see the Arcade guide.
  • A disc game is missing its tracks. A .cue or .gdi needs every track file next to it, with the names it lists. Converting to .chd avoids this.
  • A zipped disc or PSP game. Unzip it; disc images aren't played from zips.
  • A damaged file. Copy it again.

I don't see my games, or a folder is missing

  • The folders are made on Retro Launcher's first run; start it once, then add games.
  • Check the folder name and the file type for the system in Systems: a game in the wrong folder, or with a type that system doesn't use, isn't listed.
  • Games added while Retro Launcher is open appear the next time it starts (or right away with Network transfer).
  • If Settings > Hide consoles with no games is on, empty systems aren't shown.

Slow games or crackling sound

  • PSP, Dreamcast, N64: they draw above their original resolution by default. If a game struggles, lower the resolution option in the pause menu's Core options. It's remembered, and applies to every game on that emulator.
  • Saturn is the heaviest system. It already skips a drawn frame when it falls behind, to keep the sound going.
  • A few stutters while a game is loading are normal.

The game is on the wrong screen or sideways

  • For one game: Home on it > Screen. For all games: Settings > Default game screen.
  • Upside down on the playfield? Change Settings > Playfield game rotation.

Artwork is missing

  • Run Settings > Download artwork with the cabinet online.
  • Games it found no cover for are listed in media/art-not-found.txt. Usually their file names are too far from the official title; renaming the file to its No-Intro name helps. Or add the cover yourself (how).
  • PSP, Game Boy Color and Lynx have no game logos online, so their DMD shows the console instead.

Network transfer won't connect

  • The computer or phone must be on the same network as the cabinet.
  • Type the address exactly as the cabinet shows it, including the port (for example :8081).
  • If the screen says there's no network connection, connect the cabinet by cable or Wi-Fi first.

Reporting a problem

Open an issue on GitHub with:

  1. What you did and what happened.
  2. The game and system.
  3. external/retro-launcher/data/launcher.log from the USB stick, attached. It records what Retro Launcher and the emulator did.

Lines worth knowing in the log: FAILED: and core error: (why a game didn't start), stats: (frames per second and sound while playing), art:, transfer: and update: (those features).
