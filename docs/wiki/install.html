Installing & updating

From the download to the first game, and how Retro Launcher keeps itself up to date.

What you need

  • An AtGames Legends Pinball 4KP or HDP.
  • A USB stick for the cabinet (the one you use for External Applications).
  • Your own games. Retro Launcher comes with none.
  • An internet connection on the cabinet, for artwork and updates (optional).

Install

  1. Download the latest release zip (retro-launcher-v<version>.zip).
  2. Unzip it. You get a single external folder.
    • Mac: double-click the zip; the external folder appears next to it.
    • Windows: right-click > Extract All. Windows suggests a folder named after the zip; either extract straight to the USB stick, or open that folder and copy the external folder out of it.
  3. Copy external to the root of the USB stick. If the stick already has an external folder, merge them.
  4. Start it. Plug the stick into the cabinet and open Retro Launcher from the External Applications menu.

Nothing on the cabinet is changed: no firmware changes, no root. Take the stick out and the cabinet is exactly as it was.

The first run

The first time it starts, Retro Launcher makes its folders on the stick: one in roms/ for every system, plus saves/, system/ and data/. Each system's folder gets a README.txt listing the file types it takes and any BIOS it can use.

So the easiest way to start: run it once, put the stick back in your computer, and fill the folders it made. (You can also make a folder yourself, with the system's exact folder name from the Systems guide.)

The folder layout

external/retro-launcher/
  retro-launcher.elf / .png / .xml   the app
  roms/<system>/                    your games
  saves/<system>/                   in-game saves and save states
  system/                           BIOS files (see Systems), PPSSPP's files
  cores/                            the emulators
  media/<system>/                   box art, logos, bezels, the console picture
  data/                             settings, the log, reports
  licenses/                         license texts

Updating

Settings > Updates checks for a newer release on GitHub. Press A on it to check now; on a new version, press A again and choose Install and restart.

  • Only the files that changed are downloaded into place; everything is unpacked and checked before anything is replaced.
  • Your games, saves, settings, artwork and BIOS files are never touched, and neither are your own retro-launcher.png / .xml.
  • Retro Launcher also checks once a day by itself and shows a message when a new version is out.

By hand: download the new release and copy its external folder over the old one. Your games and settings aren't in a release, so nothing of yours is overwritten.

Removing it

Delete external/retro-launcher/ from the stick. Copy roms/ and saves/ somewhere first if you want to keep your games and saves.
