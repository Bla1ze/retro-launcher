GUIDES / SYSTEMS

Systems

All 21 systems: the folder, the file types, the emulator, the BIOS files they can use, and what each cabinet button does.

Buttons are written as CABINET console button. They're the defaults; change them for one game or a whole system with Home > Controls (see Controls & settings). Settings > BIOS check shows which BIOS files you have and where missing ones go.

Arcade

Arcade

Folder
roms/arcade/
Files
.zip (as they are, never unzipped)
Emulator
FBNeo or MAME 2003-Plus, picked per game
BIOS
BIOS / parent zips in roms/arcade/ required – only the games that need one, e.g. neogeo.zip, pgm.zip, or a clone's parent
Buttons
A Button 1B Button 2X Button 3Y Button 4LB Button 5RB Button 6Rewind CoinStart Start
Notes
Each zip is checked against both emulators' ROM lists; see the Arcade guide. Vertical games go to the playfield.

Neo Geo

Folder
roms/neogeo/
Files
.zip (FBNeo sets, e.g. mslug.zip)
Emulator
FBNeo
BIOS
neogeo.zip in roms/neogeo/ or system/fbneo/ required – one in roms/arcade/ is copied over for you
Buttons
A AB BX CY DRewind CoinStart Start
Notes
Zips that aren't Neo Geo games are listed with a note to move them to roms/arcade/. Neo Geo games in roms/arcade/ play there too.

Dreamcast

Folder
roms/dreamcast/
Files
.chd, .cdi, .gdi, .cue, .m3u
Emulator
Flycast GPU
BIOS
dc_boot.bin in system/dc/ good to have – needed for homebrew and some conversions; official discs run without it
dc_flash.bin in system/dc/ good to have – goes with dc_boot.bin
Buttons
A AB BX XY YLB2 L triggerRB2 R triggerStart Start
Notes
A .gdi game can be a folder of its own: roms/dreamcast/Game/disc.gdi. Renders at 2x by default.
