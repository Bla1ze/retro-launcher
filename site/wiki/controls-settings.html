Search

Type with the on-screen keyboard (A types, LB deletes, RB jumps to the results). It searches every system at once.

The Home menu on a game

  • Play, and Add to / Remove from Favorites.
  • Screen: Default, Backglass or Playfield, for this game.
  • Emulator (arcade): which emulator plays it.
  • Start with (ColecoVision): the keypad number auto-start presses.
  • Controls: the button layout for this game or its whole system.
  • Search, and Remove game, which moves it to the trash (Settings > Empty trash deletes it for good).

The pause menu

  • Resume.
  • Save state / Load state: one save slot per game.
  • Reset.
  • Core options: the emulator's own settings, such as resolution. Remembered, for every game that emulator plays.
  • Rotate picture: turns the picture a quarter at a time (off, turned right, upside down, turned left), for games that come up sideways, such as PSP, Game Boy Advance and Dreamcast games with a vertical (TATE) mode. Remembered for that game.
    • Turn controls with it (shown when the picture is turned sideways): the joystick turns with the picture, so up is up on the screen. Switch it off for a game that turns its own controls.
  • Swap players 1 and 2 (shown when a second controller is connected): see More players.
  • Change disc: multi-disc games only.
  • Quit to menu.

Quitting also saves a resume point. Next time you start the game, it asks: Continue where you left off or Start from the beginning.

More players

The cabinet's own controls are player 1. Each USB or Bluetooth controller you connect becomes the next player, up to four, in the order they connect. With no cabinet controls, the first controller is player 1.

  • Every player gets the same button layout as player 1, so arcade games take player 2's coin and Start from player 2's controller.
  • When a second controller is connected, the pause menu shows who is who.
  • Swap players 1 and 2 in the pause menu makes a controller player 1, for playing on it alone. It's remembered for every game.
  • Menus and the pause menu answer every controller.

Changing the buttons

Home on a game > Controls. Choose whether the layout is for this game or the whole system, then either:

  • pick a preset: Default, Swap A and B, or Flippers as A and B; or
  • select a console button, press A, then press the cabinet button you want for it. A button that's already used swaps jobs.

Menus and the pause menu always use the default layout, so a remap can't lock you out. While you play, the playfield card shows the layout in use.

Settings

The Settings row is under Favorites on the consoles list. Change a setting with Left / Right.

Picture settings apply to the next game you start. Below the settings are these actions:

  • Download artwork: box art, logos and bezels for your games (more).
  • Network transfer: send games from a browser (more).
  • BIOS check: which BIOS files your systems can use, required or good to have, found or missing, and where each goes.
  • Updates: install a newer version (more).
  • Empty trash: delete the games removed with Home > Remove game, for good.

Settings files

For tinkerers: settings live in data/settings.cfg (key = value), and emulator options changed in the pause menu in data/core-options.cfg, in RetroArch's format, so options from a RetroArch setup can be copied in. The README lists every key.
